## 🚀 Featured Projects

#### [🏭 Factory Maintenance Management System](https://github.com/jo-barbosa/manutencao-api)
*Event-driven microservices platform to manage industrial maintenance actions and system availability (May 2026 – Jul. 2026).*

- 🏢 **Context:** Internal enterprise solution designed to digitize maintenance workflows and real-time equipment status tracking.
- 🧠 **Key Concepts:** Domain-Driven Design (DDD), Event-Driven Architecture (Pub/Sub), Database-per-Service, Clean Architecture.
- ⚙️ **Architecture:** Federated GraphQL Gateway forwarding operations to autonomous FastAPI microservices, coupled with RabbitMQ async messaging and a Streamlit dashboard.
- 🛠️ **Stack & Practices:** Python 3.12, FastAPI, Strawberry GraphQL, RabbitMQ, Streamlit, Docker Compose, DDD.

#### [✈️ AlSafe - Flight Control & Management System](https://github.com/jo-barbosa/AIsafe-app)
*Scalable flight management backend with domain validation and simulation engine (Feb. 2026 – Jun. 2026).*

- 🎯 **Achievements:** Graded **18/20**.
- 🧠 **Key Concepts:** Domain-Driven Design (DDD), Domain Specific Language (DSL) parsing with ANTLR.
- ⚙️ **Architecture:** TCP/UDP network servers deployed on AWS EC2, concurrent C simulation engine.
- 🛠️ **Stack & Practices:** Java 21, JPA/Hibernate, PostgreSQL, C, AWS, CI/CD (GitHub Actions).

#### [🚂 Logistic-on-Rails](https://github.com/jo-barbosa/Logistic-on-Rails)
*End-to-end railway logistics management solution (Integrative Project, Sep. 2025 – Jan. 2026).*

- 🏆 **Achievements:** Graded **18/20** and awarded an **Honorable Mention** (LAPR3).
- 🧠 **Key Concepts:** Route and network optimization using KD-Trees (2D) and graph algorithms (Dijkstra, Max Flow).
- ⚙️ **Architecture:** TDD-driven tiered backend integrated with database and embedded components.
- 🛠️ **Stack & Practices:** Java 17, Oracle SQL/PLSQL, C/Assembly (RISC‑V), JavaFX, TDD.
